# Prompts

One file per AI task (BUILD_PROMPT.md section 10). You can edit the wording here without touching code.

- Sections start with a line like `=== system ===` or `=== user ===`.
- Words in `{curly_braces}` are filled in by the code. Keep them spelled exactly the same.
- Other braces (like the JSON examples) are left alone.
- Restart the app after editing so it loads the new wording.
- Keep the HARD RULES. They keep the site safe for everyone.
